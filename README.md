# Part II — The Climb (stable build)

Controls:
- A / D or Arrow Keys — move
- Space — jump
- E — use a gate
- R — recover to the latest checkpoint

Stability changes:
- Fragments persist across refreshes.
- Checkpoints persist across refreshes.
- Room/gimmick progress is saved per level.
- Decay (weight) platforms only decay while the player is actually standing on them.
- Weight platforms recover when left alone and give a long warning before collapsing.
- The player can safely recover after a collapse or missed jump.
- Gate transitions are explicit; there are no automatic right-edge level changes.
- The final Part II document link is preserved.
